# 阶段 6 记录：数据统计页（周 / 月 / 年）

日期：2026-09-30 ｜ 状态：✅ 完成（构建验证通过）

## 做了什么
- `src/pages/StatsPage.tsx`：
  - 周 / 月 / 年三个 tab + ‹ › 时段前后导航（本周/本月/今年为默认，可回看历史时段，不允许看未来）。
  - 五口径汇总卡：消费冲动（含次数）/ 实际支出 / 已节省 / 即将支出 / 存入基金。
  - 时段内有手动调整时，单列"手动调整"注释块，口径透明。
  - 周：7 天分组柱状图（冲动/节省/支出）；月：逐日趋势线（冲动/节省）+ 动机来源分布（堆叠条 + 图例含次数与百分比）；年：12 个月分组柱状图。
- `src/components/charts.tsx`：自绘 SVG（BarChart / TrendLine / DistBar），零图表库依赖，配色即应用语义色（冲动灰 / 节省墨绿 / 支出赭红），符合"不要大量彩色图表"的要求。
- 统计页底部预留"手动调整"入口按钮（阶段 7 实现 AdjustDialog）。

## 怎么做的
- 自绘 SVG 而非 ECharts/Recharts：体积（+2KB vs +300KB+）、审美完全可控、符合极简纸感。
- 数据量级为个人日记（几百条），全量载入 + 内存过滤即可，无需复杂查询。
