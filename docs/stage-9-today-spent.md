# 阶段 9：第四个灵动岛「今日已支出」（v0.3.0）

日期：2026-10-02 ｜ 需求来源：用户实测反馈 —— 「已支出已经统计到了，加个新模块便于更全面地了解」

## 一、做了什么

1. **新增第四个灵动岛模块「今日已支出」**
   - 与前三个（已节省 / 即将支出 / 大件基金，都是**累计值**）不同，这是**当日流量**指标
   - 口径：当日 00:00 起所有记录的 `actualAmount` 之和 + 当日 `ACTUAL` 类型的手动调整流水
   - 语义：0 元时数字用中性灰（`--ink-3`）而非红色 —— 「今天还没花钱」是件好事，不该红着脸显示
   - 图标：新增购物袋 `cart` 图标（与「即将支出」的箭头图标区分）
2. **明细面板第四种形态**（单击岛内该模块弹出）
   - 标题「今日已支出」+ 当日总额（红）
   - 明细列表：当日每笔实际支出（内容、`−¥X`、时间 HH:mm）+ 当日 ACTUAL 手动调整
   - 空态文案：「今天还没有支出」
   - 底部操作：记一笔 / 手动调整（预设 ACTUAL 口径）
3. **圆点指示器可点击**：原来 4 个小圆点只是视觉指示，现在点一下直接跳对应岛（触控目标 16px）
4. **展开态页面留白自适应**：四岛竖排比三岛更高，把展开状态提升到全局（`uiStore.islandExpanded`），
   页面底部留白在展开时自动从 168px 增到 300px，最后一条记录不会被压在岛下面

## 二、怎么做的

- **统计口径下沉到 `db/stats.ts`**：新增 `todaySpent(entries, adjs)`，与其他口径（`statsOf` / `fundInOf` / `adjSum`）放在一起，
  保证「岛 = 明细面板 = 统计页」用的是同一套推导，不会出现两套数字。
- **零新依赖、零结构变动**：IslandBar 的圆点与竖排本来就是按 `mods` 数组动态渲染的，加一个模块即自动变成四岛；
  `IslandDetail` 原先是 `0/1/else` 三分支，改为 `0/1/2/else` 并补第四个分支。
- **样式只加不改**：新增 `.page-scroll.with-island-expanded` 一条规则；圆点改为伪元素过渡，保证 44px 触控友好。

## 四、遗留与边界

- 「今日」按设备本地时区 00:00 切分（与日记的日期分组一致）；跨时区旅行时以设备时区为准。
- 该模块只统计**实际支出**（已购买 + ACTUAL 调整），不含「即将支出」——两者语义不重叠，不会重复计数。
