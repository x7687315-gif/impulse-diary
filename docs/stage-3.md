# 阶段 3 记录：新增消费记录全流程

日期：2026-09-30 ｜ 状态：✅ 完成（构建验证通过）

## 做了什么
`src/components/EntryForm.tsx`（含外层 EntryFormGate）：
- 字段：想买什么（文本）/ 预计多少钱（大号金额输入，inputMode=decimal）/ 为什么想买（5 动机 chips）/ 决策分区（随心花/缓冲期/谨慎考虑 + 可"暂不分类"，不强制）/ 五种决策态。
- 决策态联动字段：已购买 → 实付额（留空=同预计）；替代消费 → 替代花费（留空=¥0）；延迟决定 → 24/48/72h 缓冲选择（默认读偏好）。
- 基金拨付：RESISTED/SUBSTITUTED 且有节省额时出现，默认全额拨入，可选目标（ACTIVE 目标下拉）；无目标时温和提示而不是强制。
- **实时金额流转预览**：冲动/实际支出/已节省/大件基金四行 + 中性注释文案（按决策态切换），严格遵守"不评判"原则。
- 编辑/删除：点便签进入编辑；删除有确认并说明统计联动撤销。
- 保存正反馈 toast："+¥21 已存入「真正喜欢的衣服」· 距离目标又近了 ¥21"；跨过目标线时提示"目标达成！可以真正拥有它了"。
- 金额推导唯一入口 = `deriveAmounts`（与规格 §4 矩阵一致），表单预览与入库共用，杜绝两套逻辑。
