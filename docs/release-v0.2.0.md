# v0.2.0 手机版发布说明

日期：2026-10-01 ｜ 类型：功能 + 优化 + 安全 ｜ 包：`impulse-diary-v0.2.0-dist.zip`（113 KB）

## 新增：清理历史数据

位置：设置 → 清理历史数据。防止长期使用后数据撑爆存储。

- **范围可选**：30 天前 / 3 个月前 / 1 年前。
- **可选是否连同清理**手动调整流水（保留时统计基线不变）。
- 执行前显示将删除的数量与截止日期，**双重确认**；页面提示先导出备份。
- 目标（goals）与偏好不受影响；清理后所有统计实时重算。

## 性能优化（系统优化要求）

- **日记查询走索引**：按所选时间范围（今天/3/7/30 天）直接用 `createdAt` 索引区间查询，不再整表加载 —— 记录量增长到几千条也不影响滑动流畅度。
- 动画全部使用 transform/opacity（合成层，不触发重排）；图表为轻量自绘 SVG。
- 预缓存总量 308 KB，首屏即离线可用。

手机安全性检验说明：本应用以 PWA 形式经 Chrome「安装应用」入口安装，**不走「未知来源应用安装」通道**，不申请任何敏感权限（无定位/通讯录/存储权限申请），ColorOS 不会弹出安全风险拦截。

## ColorOS（realme GT 5 Pro，RMX3888）安装步骤

> ColorOS 检测到 PWA 时**不会自动弹窗**，需要手动触发（realme/OPPO/一加通用行为）。

1. 手机 Chrome 打开发布的 HTTPS 链接（见发布消息）。
2. 右上角 ⋮ 菜单 → 点 **「安装应用」**（或「添加到主屏幕」）。
3. 若提示权限：系统设置 → 应用管理 → Chrome → 授权「创建桌面快捷方式」。
4. 确认后桌面出现「攒钱日记」图标，点开即全屏运行，离线可用。
