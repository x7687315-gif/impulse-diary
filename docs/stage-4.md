# 阶段 4 记录：底部灵动岛 + 缓冲期到期提醒

日期：2026-09-30 ｜ 状态：✅ 完成（构建验证通过）

## 做了什么
`src/components/IslandBar.tsx` —— 按用户原创交互实现：
- **单岛默认**：白胶囊 + 圆图标 + 标签 + 金额，居中悬浮于底部（FAB 悬浮其右上方）。
- **左滑/右滑切换**三模块（已节省 → 即将支出 → 大件基金循环），pointer events 实现（阈值 36px、横向>纵向），方向跟随滑动方向；页码点指示当前模块。
- **双击展开**为竖排三岛（依次浮出动画 55ms stagger），基金岛带进度条；再双击收起（恢复滑动位置）。
- **单击明细**：240ms 定时器与双击仲裁；明细面板 `IslandDetail.tsx` 从岛上方滑出——
  - 已节省：最近节省记录 + 手动调整流水；
  - 即将支出：PLANNED 列表（标"待支付"）+ 快捷入口；
  - 大件基金：各目标进度条 + 拨付明细 + 跳转目标页。
- 岛上数据全部实时推导（entries + adjustments 汇总，含手动调整口径叠加）。
`src/components/BufferBanner.tsx`：日记顶部琥珀色提醒条——「有 N 笔缓冲期到了，做个决定吧」，展开逐条显示金额与已等待时长，"去决定"直达编辑表单。应用内提醒方案（不用系统推送，规避 ColorOS 杀后台）。

## 怎么做的
- 单/双击冲突：click 定时 240ms 仲裁（与交互原型同思路）；手势用 Pointer Events 统一鼠标/触屏。
- 展开态动画 `cubic-bezier(0.2,0,0,1)`，与设计规范一致；`prefers-reduced-motion` 降级。

## 验证
- 构建通过；岛数据与表单增改实时联动（useLiveQuery）。
