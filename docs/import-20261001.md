# 专属数据导入页（2026-10-01，已脱敏）

用途：把用户口述的真实记录一键写入手机端 App（同源直写 IndexedDB，
并标记 seeded=true 防止示例数据混入）。

- 模板：`tools/import-template.html`（不含数据，运行时 fetch 同目录 `import-data.json`）
- 含真实数据的数据包与备份文件**不入库**（.gitignore 已加规则，历史已清洗）
- 流程：生成 JSON → 临时部署 import 页 → 用户手机一键导入 → **确认后立即用干净构建覆盖发布**
- 教训归档：`git add -A` 会把工作区新文件卷进提交（真实备份 json 曾因此入库），
  发布公开仓库前必须做「跟踪文件清单审计 + 历史清洗」
