# 攒钱日记（impulse-diary）

> **不是记录我花了多少钱，而是记录我如何面对自己的消费欲望。**

一个「消费冲动可视化 / 压力消费转化」的个人应用。它不是记账软件——没有账本、没有报表、没有评判。它只做一件事：**在消费欲望出现的瞬间记下一笔，看着你如何决定，然后让没花掉的钱变成你真正想要的东西。**

```
消费欲望出现 → 我记录它 → 我做出决定 → 钱没有消失
            → 它变成了我的目标基金 → 我最终买到了真正喜欢的东西
```

## 核心功能

- **📓 消费日记**：手机便签本质感的时间流。每条记录 = 想买什么 / 多少钱 / 为什么想 / 最终决定，像日记一样自然。
- **五种决策态**：已购买 / 已放弃 / 替代消费 / 延迟决定（缓冲期）/ 已计划，每种状态有清晰的金额去向（见下方矩阵）。
- **四妙灵动岛**：底部悬浮胶囊，默认单岛，**左右滑动**（或点圆点）切换「已节省 / 即将支出 / 大件基金 / 今日已支出」，**双击展开**竖排四岛，**单击**看明细与手动调整。前三是累计值，「今日已支出」是当日流量——今天还没花钱时它显示中性灰，而不是红色。
- **🎯 大件目标基金**：忍住一次冲动，就能把那笔钱存进「真正喜欢的衣服 ¥133 / ¥300」——每存一笔，距离目标又近一点。
- **📊 数据统计**：周 / 月 / 年三个尺度，五口径汇总 + 自绘极简 SVG 趋势图 + 消费冲动来源分布。
- **✋ 手动调整**：系统统计永远可以被人工纠正——改金额必须写原因，全部流水永久保留。
- **导出 / 导入**：一键 JSON 备份，电脑测试数据可以搬家到手机。

## 钱的去向（数据逻辑的核心）

| 决策 | 冲动金额 | 实际支出 | 已节省 | 即将支出 |
|------|:---:|:---:|:---:|:---:|
| 已购买 BOUGHT | ✓ | ✓ | — | — |
| 已放弃 RESISTED | ✓ | — | ✓（可拨入基金） | — |
| 替代消费 SUBSTITUTED | ✓ | 差额（如有） | ✓（可拨入基金） | — |
| 延迟决定 DEFERRED | ✓ | — | —（缓冲期后补决定） | — |
| 已计划 PLANNED | ✓ | — | —（付款后转已购买） | ✓ |

原则：**不阻止花钱，也不评判消费**。界面里只有中性的记录语言。

## 技术栈

- **React 18 + TypeScript + Vite**（移动端优先，全屏自适应，safe-area 适配真机）
- **Dexie.js**（IndexedDB）+ useLiveQuery —— 数据是唯一事实源，统计全部实时推导
- **zustand**（轻量 UI 状态）
- **vite-plugin-pwa** —— 可安装、离线可用的 PWA
- 自绘 SVG 图表，零图表库依赖
- Local-first：无后端、无账号、无云端依赖

## 快速开始

```bash
npm install        # 国内网络：项目 .npmrc 已配置 npmmirror 镜像，无需额外设置
npm run dev        # 开发模式（热更新）
npm run build      # 类型检查 + 生产构建（tsc --noEmit && vite build）
npm run preview    # 本地预览构建产物（默认 http://localhost:4173）
```

> Windows + 国内环境已知坑与对策见 [`docs/npm-env-notes.md`](docs/npm-env-notes.md)（npm 镜像 / 可选依赖 bug / EBUSY）。

### 装到手机上

构建产物是标准 PWA。把 `dist/` 发布到任意 HTTPS 静态托管后，用手机 Chrome 打开 → 「添加到主屏幕」，即可获得独立图标、全屏运行、离线可用的应用。数据存在手机本地，与电脑互不相通，需要搬家时用「设置 → 导出 / 导入」。

## 目录结构

```
src/
├── db/            # Dexie 单例、统计推导（stats.ts 是金额逻辑的唯一实现）、备份
├── state/         # zustand：页面 / 弹窗 / toast
├── components/    # 便签卡、灵动岛、记录表单、调整弹窗、图表
├── pages/         # 消费日记 / 数据统计 / 我的目标 / 设置
├── seed.ts        # 首次启动的示例数据
└── styles.css     # 设计 tokens（纸感 + 几何极简）与全部组件样式
docs/              # 设计规范、开工前调研简报、各阶段记录、测试报告
```
